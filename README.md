# microsoft-markitdown
A simple Python script that converts PDF, Word, Excel, PowerPoint, and HTML files into clean Markdown using Microsoft MarkItDown.

# Credit
Github link (microsoft-markitdown): https://github.com/microsoft/markitdown
Youtube tutorial: https://youtu.be/UFEVQdJeWeQ?si=-1aJlGma2DeS7zJ3

# How to run in powershell 
it can also convert youtube video into .md file just replace the path with the actual URL
